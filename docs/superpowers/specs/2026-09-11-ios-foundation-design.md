# PENTAPHOR iOS 첫 사용 버전 명세

상태: 사용자 승인 디자인과 개발 착수 요청을 바탕으로 구현. 월요일 규칙은 2026-09-11 사용자가 직접 선택했다.

## 목적과 범위

SwiftUI 네이티브 iPhone 앱에서 나만의 퀘스트를 등록하고 주간·월간 목표를 채우며 다섯 파라미터를 쌓는다. 첫 버전은 로그인 없이 오프라인으로 작동하고 SwiftData로 기기에 기록을 저장한다. 최소 iOS 17.0, 외부 런타임 의존성 없음. 앱스토어 업로드·서명 계정 변경·월간 리캡·알림·클라우드 동기화는 이번 범위 밖이다.

## 제품 규칙과 수용 기준

- Q01: 이름은 앞뒤 공백을 제거한 1~40자. 아트는 기존 60개 중 선택한다. 아트 선택 화면에는 카테고리와 그림만 보이고 아트 이름은 화면 읽기와 검색용으로만 사용한다. 아트 변경은 퀘스트 이름을 변경하지 않는다.
- Q02: 목표 주기는 주간 또는 월간, 횟수는 1~99의 정수. 완료당 체력·지식·끈기·매력·용기에 음수가 아닌 정수 포인트를 배분하며 합계는 최대 2. 0도 허용한다.
- Q03: 이름·아트·보상은 수정 가능하다. 이미 기록한 보상은 수정의 영향을 받지 않는다. 현재 기간에 기록이 있으면 목표 횟수 변경은 다음 기간부터 적용한다. 기록이 없으면 현재 기간부터 적용한다. 주기는 첫 기록 이전에만 변경 가능하다. 변경 제한을 화면에서 설명한다.
- Q04: 보관한 퀘스트는 현재 목록에서 빠지며 추가 완료를 막는다. 기록과 파라미터는 보존하고 보관 목록에서 복원할 수 있다.
- T01: 주간은 사용자 집계 시간대의 월요일 00:00부터 다음 월요일 00:00까지, 시작 포함·끝 제외다. 월간은 매월 1일 00:00부터 다음 달 1일 00:00까지다.
- T02: 사용자가 선택한 규칙: 새 주는 월요일 00시에 시작하고 지난주 기록만 월요일 09시까지 허용한다. 월요일 00:00 이상 09:00 미만일 때 주간 퀘스트에 ‘지난주에 기록’ 선택을 제공한다. 기본은 이번 주다. 09:00 정각부터 지난주 기록을 거절한다. 월간에는 이 예외가 없다. 선택한 기간의 목표를 적용한다. 지난주에 존재하지 않았던 퀘스트의 소급 완료는 거절한다.
- T03: 초기 실행 시 기기 시간대를 집계 시간대로 저장한다. 여행·기기 시간대 변경이 과거 기록을 재분류하지 않도록 이 시간대를 유지하고 파라미터 화면에 표시한다. 이번 버전에서는 집계 시간대를 변경하지 않는다. Calendar의 달력 연산을 사용하여 DST, 윤년, 연도 경계를 처리한다.
- C01: 완료 1회는 불변의 기간·해당 기간 목표·보상 스냅샷을 가진 활동 기록이다. 같은 요청 ID를 재처리해도 추가 적립하지 않는다. 목표를 초과해도 활동 기록과 기본 보상은 적립한다.
- C02: 특정 퀘스트가 연속된 두 기간을 달성하면 두 번째부터 각 달성 기간당 끈기 +1. 세 번째에는 추가 +1이다. 주간·월간 모두 동일하다. 보너스는 해당 기간에 한 번만, 퀘스트 기본 2포인트와 별도로 부여한다. 현재 기간이 아직 미달이어도 이전 완료 기간들의 보너스는 유지한다.
- C03: 기록은 ‘되돌리기’로 무효화하며 횟수·기본 보상·연속 달성 보너스를 다시 계산한다. 과거 달성을 무효화하여 이후 기간의 연속 조건이 깨지면 그 보너스도 정확하게 회수한다. 이미 무효화된 기록을 또 되돌려도 추가 차감하지 않는다. 퀘스트 보관 후에도 되돌릴 수 있다.
- D01: 총 파라미터는 활성 활동 보상 합과 유효 연속 달성 보너스에서 도출한다. 별도의 가변 누적 스탯을 진실의 원천으로 저장하지 않는다. 완료·되돌리기·퀘스트 수정은 저장 성공 후에만 화면 상태에 반영한다.
- D02: 앱 재실행 후 퀘스트·기간 목표 변경·활동·무효화·집계 시간대가 보존된다. 저장 오류나 알 수 없는 데이터 버전은 사용자에게 표시하며 빈 상태로 덮어쓰지 않는다.
- U01: 기존 아이보리·잉크·청록·골드, 큰 행위 아트, 경사진 타이포그래피를 사용한다. 홈·생성/수정·아트 선택·달성·파라미터·기록·보관 목록을 제공한다. 원본 60종과 수정된 기타/고양이/설거지 이미지를 사용한다.
- U02: 달성은 같은 아트 등장 → 획득 파라미터 표시 → 증가한 오각형 꼭짓점 탄성 순서다. 애니메이션 감소 설정에서는 바로 최종 형태를 보여준다. 음향 없이 햅틱을 사용한다. 2포인트 제한은 UI와 도메인 양쪽에서 검증한다.
- U03: 첫 실행은 빈 목록이며 테스트 데이터로 사용자 기록을 오염시키지 않는다. 테스트 실행 인자는 격리된 테스트 저장소만 사용한다. 상태를 테스트 목적으로 초기화하는 코드는 앱 내부 제품 동작으로 노출하지 않는다.

## 구조

2026-09-14 수정 진입 보완: 퀘스트 목록의 각 항목에 연필 아이콘과 ‘수정’ 텍스트를 항상 표시한다. 이 진입은 기존 이름·설정이 채워진 수정 화면을 열며, 완료 횟수를 올리지 않는다. 저장한 변경은 기존 퀘스트에 적용되고 앱 재실행 후에도 보존된다.

`Packages/PentaphorCore`: Foundation 기반 도메인, Calendar 기간 계산, SwiftData 저장소. macOS에서 `swift test`로 날짜·집계·저장 통합 테스트를 실행한다.

`Pentaphor`: SwiftUI 앱과 화면, PNG 리소스, 카탈로그. 도메인 계산을 화면에 복제하지 않는다. SwiftData는 versioned Codable 상태를 하나의 저장 행에 기록하여 한 트랜잭션으로 저장한다. 개인용 첫 버전에서는 충분히 단순하며 추후 마이그레이션 가능하다.

`PentaphorUITests`: 시뮬레이터에서 생성→완료→되돌리기 및 재실행 보존을 확인한다. 외부 배포 없이 시뮬레이터 빌드와 테스트로 마무리한다.

## 구현 결정

사용자가 별도로 정하지 않은 목표 변경 정책과 시간대 고정은 기록의 안정성을 위한 첫 버전 결정이다. 추후 정책을 바꾸면 마이그레이션과 해당 테스트도 함께 변경한다. 앱 번들 ID는 개발용 `app.pentaphor.personal`로 설정하고, 실제 배포 직전에 사용 가능 여부와 팀 설정을 확인한다.
