# 퀘스트 메모

사용자 요청: iPhone 미리알림의 메모처럼 퀘스트에 상세 설명을 적을 수 있게 한다.

- 생성·수정 화면의 이름 바로 아래에 선택 입력인 ‘메모’ 여러 줄 입력칸을 제공한다.
- 일반 텍스트, 줄바꿈, 한글과 이모지를 그대로 보존한다. 비워서 저장하면 메모를 지운다. 작성하지 않아도 퀘스트 생성 가능하다.
- 목록에서는 비어 있지 않은 메모를 최대 두 줄로 미리 보여준다. 전체 내용은 기존 ‘수정’ 진입에서 읽거나 수정한다.
- 취소하면 입력 전 상태를 유지한다. 저장 성공 후에만 화면에 반영하며 앱 재실행 후에도 유지된다.
- 메모 수정은 완료 횟수·획득 포인트·완료 스냅샷을 바꾸지 않는다. 메모는 퀘스트 정의에 속한다.
- 기존 v1 JSON에 메모 키가 없어도 빈 메모로 읽는다. 기존 퀘스트와 기록을 초기화하지 않는다.

구현 순서: 도메인/기존 저장소 호환 테스트 RED → 메모 저장 GREEN → UI 인수 테스트 RED → 입력과 목록 미리보기 구현 → 전체 코어 및 UI 검증, 아이폰용 서명 빌드.

저장 형식은 기존 버전의 선택 필드 `notes`로 확장한다. 기존 호출자가 update에서 notes를 생략하면 메모를 유지하고, 빈 문자열을 명시하면 삭제한다. SwiftData의 저장 모델 구조는 유지한다.
