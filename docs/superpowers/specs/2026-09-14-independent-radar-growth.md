# 파라미터 도형의 독립 성장

사용자가 승인한 방향: 눈금은 정확한 측정값보다 성장의 모양을 전달한다. 누적 점수는 숫자로 정확히 보여주며, 다른 스탯이 올랐다고 기존 축이 줄어들면 안 된다.

- 스탯별 성장 비율은 `점수 / (점수 + 50)`으로 독립 계산한다. 10점 약17%, 50점50%, 100점약67%, 300점약86%. 누적 점수에 상한을 두지 않는다.
- 기존 중앙의 작은 오각형과 바깥 여백을 유지하기 위해 실제 반경은 `0.15 + 0.78 × 성장 비율`로 배치한다. 눈금은 장식용이며 점수 구간을 의미하지 않는다.
- 완료 전 점선과 완료 후 도형에 동일한 함수를 사용한다. 다른 축은 움직이지 않는다.
- 달성 시 증가한 꼭짓점만 두 번 바깥으로 튀었다가 실제 새 위치에 안착한다. 포인트가 커져 실제 반경 변화가 작아져도 연출은 유지한다. 꼭짓점과 도형은 같은 좌표 계산을 사용한다.
- 동작 줄이기를 켜면 튀는 연출 없이 최종 상태를 표시한다. 실제 점수, 저장 데이터, 보너스 규칙은 바꾸지 않는다.

검증: 곡선의 대표 값과 단조 증가, 큰 점수에서의 유효 좌표, 다른 축의 독립성, 전후 좌표 연속성, 증가한 축만 튀는 연출, 동작 줄이기. 기존 UI 회귀와 시뮬레이터 화면, 아이폰용 빌드 확인.
