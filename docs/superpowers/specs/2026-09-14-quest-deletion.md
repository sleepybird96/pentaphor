# 퀘스트 삭제

사용자 요청: 수정 화면의 ‘퀘스트 보관하기’ 아래에 빨간 글씨로 ‘퀘스트 삭제하기’를 추가한다. 사용자 선택에 따라 완료 기록과 획득 파라미터는 유지한다.

- 기존 퀘스트 수정 화면에만 삭제 버튼을 표시한다.
- 확인창에서 기록·파라미터 유지와 복원 불가를 안내한다. 취소는 아무것도 변경하지 않는다.
- 삭제한 퀘스트는 활성 목록과 보관함에서 사라지며, 다시 완료·수정·복원할 수 없다.
- 기록 화면의 이름·아트, 완료 스냅샷, 누적 포인트와 연속 달성 보너스를 유지한다. 사용자가 기록 자체를 되돌리는 기존 기능은 계속 동작한다.
- 기록 참조와 보너스 계산을 보존하기 위해 퀘스트 정의에 선택 필드 `deletedAt`을 저장한다. 기존 v1 데이터는 필드가 없으면 nil로 읽는다.
- 저장 실패 시 화면을 닫지 않고 오류를 표시하며 퀘스트와 기록을 유지한다. 재실행 후에도 삭제 상태를 유지한다.

검증: 도메인 삭제·기록/보너스 보존·수정/복원 방지, 디스크 재실행, 저장 실패, UI 취소/확인/목록·보관함 제외/기록·포인트 유지.
