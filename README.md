# PENTAPHOR

매일 채우는 체크리스트보다, 자기 페이스로 이어가는 성장을 위한 iPhone 루틴 앱.

## 첫 개발 버전

- 커스텀 퀘스트 생성·수정·보관·복원, 한 번·매주·매월 목표
- 체력·지식·끈기·매력·용기에 완료당 최대 2포인트 배분
- 반복 퀘스트별 2주/2개월째부터 연속 달성 기간마다 끈기 +1
- 월요일 00:00 새 주 시작, 월요일 09:00 전까지 명시적으로 지난주 기록 선택
- 달성·되돌리기·기록 내역·파라미터, 오각형 성장 연출과 햅틱
- 카테고리로 고르는 기존 아트 60종, 기기 내 SwiftData 저장

처음 설치하면 ‘STACK YOUR PROGRESS. / 작은 행동을 쌓아, 나를 키우다.’ 시작 안내가 열린다. 선택 닉네임과 파라미터 안내를 거쳐 첫 퀘스트를 만들거나 바로 둘러볼 수 있다. 기존 사용자는 안내를 강제로 다시 보지 않는다. 네트워크나 계정 없이 사용할 수 있다. 집계 시간대는 첫 실행 때 저장하고 유지한다. 이미 기록한 행동 포인트와 지난 기간의 목표는 스냅샷으로 보존한다. 주간·월간 목표 변경은 기록이 있어도 이번 기간부터 즉시 적용한다. 이전 버전에서 다음 기간으로 예약한 변경은 퀘스트를 다시 저장하면 즉시 적용된다.

홈은 주간·월간 구획 없이 만든 순서대로 한 목록에 표시한다. 생성 화면의 **한 번 / 매주 / 매월**에서 반복 방식을 고른다. ‘한 번’은 목표가 1회로 고정되며 기한 없이 남아 있다. 완료하면 목록에서 빠지고 기록과 획득 포인트는 유지된다. 달성 화면이나 기록 탭에서 되돌리면 포인트가 빠지고 목록으로 돌아온다. 보관·삭제 상태는 되돌리기로 바뀌지 않는다. 1회성 퀘스트에는 연속 달성 끈기 보너스가 없지만, 완료 포인트에 끈기를 직접 배분할 수 있다. 첫 기록 이후에는 되돌렸더라도 반복 방식을 변경할 수 없다.

퀘스트 목록에서 진행 횟수 아래의 **✎ 수정**을 누르면 이름·아트·목표·포인트를 수정할 수 있다. 그림이나 이름을 눌러도 같은 수정 화면이 열린다. 오른쪽 체크 버튼은 완료 기록용이다.

아트는 행동을 떠올리는 시각적 단서다. 카테고리는 아트 선택창의 탐색에만 사용하며, 생성·수정·달성 화면에서 퀘스트를 분류하는 문구로 표시하지 않는다. 이름 입력 힌트는 ‘퀘스트 이름’으로 고정하고, 아트 선택은 이름을 채우거나 바꾸지 않는다.

생성·수정 화면의 **메모**에는 준비물이나 수행 방법을 여러 줄로 적을 수 있다. 입력은 선택이며, 목록에는 최대 두 줄이 표시된다. 전체 내용은 수정 화면에서 확인한다. 비워서 저장하면 삭제되고, 취소하면 이전 메모가 유지된다.

수정 화면의 **퀘스트 보관하기** 아래에는 빨간 **퀘스트 삭제하기**가 있다. 확인 후 삭제하면 목록과 보관함에서 사라지며 복원할 수 없다. 완료 기록과 획득 파라미터(연속 달성 보너스 포함)는 그대로 남는다.

파라미터 도형은 각 스탯의 누적 점수를 독립적인 성장 곡선으로 표시한다. 한 스탯이 커져도 다른 축은 줄어들지 않는다. 눈금은 시각적 가이드이며 정확한 누적치는 숫자로 확인한다. 달성 화면에서는 증가한 꼭짓점만 두 번 튀었다가 새 위치에 안착한다. iPhone의 ‘동작 줄이기’를 켜면 최종 모양을 바로 표시한다.

## 시작 안내와 설정

상단 톱니바퀴에서 닉네임, 햅틱, 달성 연출을 조절할 수 있다. 닉네임은 선택이며, 앞뒤 공백을 제외한 20자 이내의 한 줄 이름을 기기에 저장한다. 파라미터 제목에 이름을 표시하고, 비워서 저장하면 ‘나의 파라미터’로 돌아간다.

첫 퀘스트를 만들 때 아트·목표·포인트 설명과 성장 미리보기가 표시된다. 미리보기는 기록이나 포인트를 만들지 않는다. 생성 취소 시 안내가 유지되고, 첫 저장에 성공하면 이후에는 표시하지 않는다. ‘달성 연출 간소하게’는 최종 결과를 바로 표시하며, 아이폰의 ‘동작 줄이기’ 설정도 항상 존중한다.

설정에는 집계 시간대와 월요일 9시 규칙, 파라미터·보관·삭제·되돌리기 안내, 앱 버전과 기기 내 데이터 안내가 있다. ‘시작 안내 다시 보기’는 설정과 기록을 변경하지 않는 설명용 화면이다. 퀘스트별 요일·시간 알림과 전체 알림 토글을 제공한다. 계정과 앱 자체의 자동 클라우드 동기화는 없다.

**설정 → 백업 · 복원**에서 퀘스트·메모·완료 기록·설정을 `.pentaphor` 파일로 저장한다. 파일 앱에서 iCloud Drive나 원하는 폴더를 선택할 수 있다. 불러오면 백업 날짜와 기록·파라미터 요약을 먼저 확인하며, 취소하면 현재 데이터가 유지된다. 복원은 현재 데이터를 백업 내용으로 교체한다. 복원 직전 데이터 한 개를 기기에 별도 보관해 되돌릴 수 있지만, 앱 삭제·기기 분실에 대비하려면 백업 파일을 별도로 저장해야 한다. 손상되거나 지원하지 않는 파일은 복원하지 않는다.

## 실행

검증 환경: Xcode 26.3, Swift 6.2.4, iOS 26.3.1 시뮬레이터. 배포 타깃은 iOS 17 이상이며, iOS 17 실기기 검증은 아직 하지 않았다.

1. `Pentaphor.xcodeproj`를 Xcode에서 연다.
2. `Pentaphor` scheme과 iPhone 시뮬레이터를 선택한다.
3. Run을 실행한다.

실제 iPhone 설치에는 Xcode의 Signing & Capabilities에서 본인의 개발자 Team을 선택하고 연결된 기기를 실행 대상으로 지정해야 한다. 현재 프로젝트에는 사용자가 선택한 Team을 유지하고 자동 서명을 설정했다. Bundle ID는 개발용 `app.pentaphor.personal`이다.

`project.yml`을 변경한 경우 XcodeGen으로 프로젝트를 다시 생성한다.

```sh
xcodegen generate
```

## 테스트

```sh
swift test --package-path Packages/PentaphorCore

xcodebuild test -project Pentaphor.xcodeproj -scheme Pentaphor \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' \
  CODE_SIGNING_ALLOWED=NO
```

사용 가능한 시뮬레이터 이름에 맞춰 destination을 바꿀 수 있다. 코어 테스트는 독립 Swift 패키지에서 실행한다. Xcode 앱 scheme은 UI 테스트를 실행한다.

UI 테스트는 DEBUG 전용 별도 저장소를 사용한다. `--ui-testing`으로 테스트 저장소를 선택하고 `--reset-test-store`를 함께 전달할 때 해당 테스트 저장소만 초기화한다. 일반 앱의 기록에는 영향을 주지 않는다.

## 진입 로딩

앱을 새로 실행하면 로고·PENTAPHOR·STACK YOUR PROGRESS와 함께 오각형의 다섯 꼭짓점이 랜덤한 순서로 튀는 진입 화면이 표시된다. 1.2초짜리 사이클을 최소 한 번 보여주며, 로딩이 늦으면 직전 모양에서 다음 사이클로 이어진다. 로딩 성공 또는 실패가 확인된 뒤 사이클 경계에서 메인·시작 안내 또는 재시도 화면으로 전환한다.

이 도형은 진입 연출 전용이며 실제 파라미터를 변경하지 않는다. 완료된 진입 화면은 다른 앱에 잠시 갔다 돌아올 때 반복하지 않는다. 아이폰 시스템의 ‘동작 줄이기’를 사용하면 정적인 도형과 짧은 전환을 적용한다. 앱의 ‘달성 연출 간소하게’ 설정은 진입 로딩에 영향을 주지 않는다.
